# Label-noise candidates

Generated by `scripts/label_noise.py` from `C:\Users\wikel\dev\xbd-data` (splits: train, test). **Nothing has been relabelled or removed.**

**Definition.** A building is a candidate if its damage class differs from the class of *every one* of its 5 nearest neighbours in the same tile (by pixel centroid). Only the four real classes take part: un-classified buildings are neither candidates nor neighbours. Tiles with fewer than 6 classified buildings are skipped, so 'eligible buildings' below is the number checked.

**What a candidate is, and isn't.** Damage is spatially clustered (`docs/observations.md`), so a building that disagrees with all its neighbours is unusual, and worth checking by eye. It isn't evidence of a mistake: a single building really can be the only one destroyed (or the only one spared) on a street. The rule is also blind to mistakes in *clusters*, e.g. a whole block labelled one class when it should be another.
